Eurex data

Eurex API

Access Eurex product parameters, contracts and trading information through one central GraphQL endpoint.

Get started in the Developer Portal

Anonymous access uses a shared, rate-limited API key. Create a dedicated key in the Deutsche Boerse Developer Portal for higher throughput.

query {
  ProductInfos(filter: { Product: { eq: "FESX" } }) {
    data { Product Name Currency TickSize }
  }
}

Data domains

Pick a domain to load a ready-made example query into the API Explorer and run it.

01

Products and contracts

Identify instruments, contract specifications and product relationships for a Eurex product.

  • ProductInfos
  • Contracts
  • FESX
02

Trading calendar

Retrieve trading phases, trading hours and holidays for market operations and scheduling.

  • TradingHours
  • Holidays
  • FESX
03

Trading parameters

Review tick-price bands and price steps alongside TES validation, approval, broker, lot-size, expiry-range and disclosure settings.

  • TickRules
  • TESProfiles
  • FESX
04

Flexible contracts

Retrieve flexible contracts with strike, maturity, settlement and open interest, alongside settlement prices for flexible contracts only.

  • FlexibleContracts
  • SettlementPrices
  • OESX
05

Option series and expirations

List the expiration calendar of an options product and its listed series with strike, call/put, delta and previous-day settlement price.

  • Expirations
  • Contracts
  • OESX

Request additional strikes

Open the Strike Window for an options product to review listed strikes per contract date and select the missing strike ranges you want to request.
