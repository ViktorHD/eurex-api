Eurex data

Eurex API

Access Eurex product parameters, contracts and trading information through one central GraphQL endpoint.

Get started in the Developer Portal

The API can be accessed anonymously with a shared API key. Shared access is rate-limited. Create a dedicated API key in the Deutsche Boerse Developer Portal for higher throughput.

Data domains

01

Products and contracts

Identify instruments, contract specifications and product relationships for a Eurex product.

02

Trading calendar

Retrieve trading phases, trading hours and holidays for market operations and scheduling.

03

Trading parameters

Review FESX tick-price bands and price steps alongside TES validation, approval, broker, lot-size, expiry-range and disclosure settings.

04

Flexible contracts

Retrieve OESX flexible contracts with strike, maturity, settlement and open-interest data, alongside settlement prices for flexible contracts only, ordered by ContractID.

Request additional strikes

Open the existing strike-window workflow to select contract dates and missing strike ranges...
