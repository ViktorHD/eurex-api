## $(date +%Y-%m-%d) - Adding aria-label and title to icon-only buttons
**Learning:** Found several icon-only buttons (using feather icons) in the index.html file that were missing semantic aria-label attributes and tooltip title attributes. Missing these attributes makes it very hard for screen reader users to understand what the buttons do, as there's no visible text inside the tags. Also found dynamic buttons being generated in JavaScript (e.g. pinBtn and expand-btn in explorer/ui.js) that were missing semantic labels.
**Action:** Added semantic aria-label and title attributes to all icon-only buttons across the main application HTML and dynamically created ones in JS. Always check both HTML template structures and dynamic element generation via JavaScript for appropriate aria labels when the element uses only icons.
